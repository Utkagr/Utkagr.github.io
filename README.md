# utkagr.github.io

Personal site, built by GitHub Pages (Jekyll). No local build needed.

- **Homepage content:** `_data/home.yml`. Empty `beyond` / `awards` lists hide those sections.
- **New post:** add `_posts/YYYY-MM-DD-slug.md` with `title`, `description`, `kind` (ml | algorithms | notes), optional `summary`.
- **Themes:** daylight, paper, midnight, terminal. Keys: `/` search, `d` light/dark, `t` theme, `b` background.

Local preview: `gem install bundler jekyll && jekyll serve` (needs Ruby ≥ 3).
